# Product Overview

**DhanYukti Spark** is a comprehensive financial management platform consisting of:

## Frontend Application (dhanayukti-spark-main)
A modern React-based web application providing users with:
- Personal financial dashboard
- Expense tracking and management
- Investment portfolio monitoring
- Tax calculation and planning
- Stock market data ("Stonks")
- User authentication and secure access

## Backend Microservices (FinSmart-Microservices)
A Spring Boot microservices architecture providing:
- **User Service**: Authentication, user management, JWT tokens
- **Expenses Service**: Expense tracking and categorization
- **Investment Service**: Investment portfolio management
- **Tax Service**: Tax calculations and planning tools
- **Stonks Service**: Stock market data and analysis
- **Razorpay Service**: Payment processing integration
- **Support Service**: Customer support functionality
- **Eureka Server**: Service discovery and registration

## Key Features
- Secure JWT-based authentication
- Real-time financial data visualization
- Responsive design with dark/light theme support
- Microservices architecture for scalability
- Integration with payment gateways
- Modern UI with shadcn/ui components
